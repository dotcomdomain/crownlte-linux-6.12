Android16 6.12 crownlte port, source-only diagnostic phase

ACK base android16-6.12-2026-09_r4, Linux6.12.92.
Reference https://github.com/SheroAbi/galaxy-s9plus-mainline-linux
Reference commit bcee6014fc2e44a4c4f1c34bca0a880d4b543ec3.
The reference is SM-G965F/S9+ and has not proved Note9 compatibility.
Original copyrights/licenses are retained in imported driver sources.

No phone writes, boot packaging, or flash scripts belong to this stage.
RAM, fixed firmware reservations and UFS/USB register windows now derive
from this exact Note9 live DT. Peripheral nodes stay disabled pending clocks
and power integration. DTB remains a compilation artifact, not boot-ready.

Captured: live FDT RAM map, fixed reservations, boot arguments, model and
UFS/USB register windows. Remaining: clock providers, PMIC/pad control, panel
and touchscreen identities, and early bootloader/shim handoff.
Then add read-only initramfs diagnostics that never mount USERDATA.

Current ROM contracts that need porting before Android boot:
- F2FS FBEv2 + inlinecrypt_optimized, original UFS FMP key descriptors.
- Vendor Mali Bifrost r38p1 JM API11.35 and Samsung private ioctl ABI and /dev/mali0, Samsung ION heap ABI.
- Samsung DECON framebuffer, EXYNOS video/G2D and camera interfaces.
- MobiCore TrustZone/keymaster and original encryption key derivation.
- SIPC modem interface, audio/ABOX and power/suspend firmware protocols.
- SELinux paths, thermal controls, firmware files and USB configfs setup.
- Rooted baseline ramdisk, existing HID/PTP/container/IPv6/USB behavior.

Build success establishes compiler/API integration only. It does not prove
boot, encryption, Android vendor ABI compatibility, or hardware operation.

FMP adapter staged from original modified crownlte source and ACK gs101 format.
FMP=1 enables hardware descriptor3, passthrough standard-key profile, F2FS FBE,
software blk-crypto fallback, and Android Binder/SELinux/cgroup prerequisites.
The software fallback algorithm contract matches existing ciphertext. Physical
encrypted transfers, plain metadata I/O, and userspace key delivery are untested.
FMP initialization errors stop probe. Encrypted userdata must stay unmounted
until physical read-only validation on recoverable data copies proves operation.
The preserved nocrypto diagnostic commit is ac0f47d51.

Resolved-config guard: address widths 48/48 and 4 KiB pages are now required.
Changing choice symbols with scripts/config also requires clearing the old
52-bit selections. SELinux requires AUDIT. The build checks actual olddefconfig
output rather than assuming requested symbols survived dependency resolution.
